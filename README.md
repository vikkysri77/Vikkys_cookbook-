## Getting Started

Each recipe is organized in its own folder with:
- `recipe.md` - The recipe details
- `ingredients.txt` - Ingredient list
- `instructions.txt` - Step-by-step instructions
- `notes.md` - Cooking notes and variations

## How to Use This Cookbook

1. Browse the folders for different meal types
2. Each recipe folder contains all information needed to prepare the dish
3. Check individual `notes.md` files for cooking tips and variations
